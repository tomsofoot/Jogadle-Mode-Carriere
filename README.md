# Jogadle — Mode Carrière

Projet officiel du deuxième jeu TomsoFoot.

## Objectif

Retrouver un joueur grâce à son parcours.

---

## Architecture

Ce dépôt contient uniquement :

- le moteur du jeu
- les règles
- l'interface
- les animations
- le design

Les données (joueurs, carrières, prêts, logos...) sont stockées dans :

Tomso-foot-Data

---

## Principe

Le jeu doit pouvoir évoluer sans jamais casser :

- les données
- les règles
- le design

Chaque partie est indépendante.
